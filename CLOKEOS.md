# ClokeOS changes

This branch holds the changes [ClokeOS](https://github.com/cloke-tech/ClokeOS) makes on top of ravynOS (base: `the default branch at the time`).
It is a fork used by ClokeOS; thank you to the original authors. The changes follow the licence of the upstream project.
Patch files and the build scripts that apply them live in ClokeOS under `clokeos-darwin/kext/audio/`.
ClokeOS uses ravynOS's HD audio driver (RavynHDAudio) via PureDarwin with fixes for AMD HD audio; the fixes are in the PureDarwin fork branch clokeos.
